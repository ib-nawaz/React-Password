# 🔐 Password Generator

A simple and clean **Password Generator** built with **React** and **Tailwind CSS**. Generate strong, random passwords instantly, customize the length, include numbers or special characters, and copy the result to your clipboard with one click.

---

## ✨ Features

- 🎚️ **Adjustable length**: choose the password length with a range slider
- 🔢 **Numbers option**: include digits (`0-9`) in the password
- 🔣 **Special characters option**: include symbols like `!@#$%^&*`
- 🔄 **Re-Generate button**: get a brand new password with one click
- 📋 **Copy to clipboard**: copy the password and see a confirmation message
- ⚡ **Auto-update**: the password regenerates automatically whenever you change the length or options
- 🎨 **Responsive UI**: styled with Tailwind CSS

---

## 🛠️ Tech Stack

- [React](https://react.dev/): `useState`, `useEffect`
- [Tailwind CSS](https://tailwindcss.com/)
- Browser Clipboard API (`navigator.clipboard`)
